Hello friends ! in today blog, i will not share any bug bounty writeup. For today, i want share a CTF writeup about a unique bug, that i still found happen on some modern website. So without further a due lets jump into the detail and how can you apply it on your bug hunting journey.

So the challenge called Bug Bank. And the description of the challenge was something like this (Shout to fhantke for the awesome challenge :D)

So of course by reading the description, Its already tingling your hacker mindset right? We need to transfer Bugs (Bugs is the currency of this website) from account A to B so that we can get enough bugs to get the premium member. So the main page of the website looks like this

There is a feature of settings and transfer bugs. So according to the description we need to abuse transfer bugs. So that we can upgrade to premium account, and to upgrade we need arround 10000 bugs.

So lets see what the transfer feature have to offer for us

Okay. so we see here we need another account ID to do our transaction. So i will make my second account which we called Thepoor. So now we have two account

Now the question is. We already have two account. but both of the bugs value is 0. So how to get 10000 bugs? We need to know the logic of how transaction works. In nutshell the logic will goes like this. The sender will get logic like (amount - money.Send) while the receiver logic ( amount + money.receive) right? So now with this logic knowledge. We can try to send a negative value. so that (amount - -money.send) (value - -value) will be positive. While the receiver (value + -value) will be negative. So lets try to send negative ammount to thepoor id.

And when i send transfer. By the logic. Therich account will get 10000 while the poor will get -10000. So here’s the result.

Yes ! our assumption about the logic of the transaction feature is correct ! For prevention developer must do rechecking of the amount or value that user input. Number 1 rules of security is that “Never trust user input” So as a developer u should check if the value that user input is already according to your plan. Anyway now let’s upgrade our account to premium with that free moneyy

Tada ! we solve this challenge !
