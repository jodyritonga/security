Research method

Follow the fracture.

The workflow separates an interesting code path from a vulnerability worth reporting.

01

Model the boundary

Map actors, data, authority, expected guards, and the security promise under test.

02

Trace source to sink

Use focused LLM-assisted review to connect attacker control to a sensitive operation.

03

Build the oracle

Test the earliest unknown edge with exact artifacts, positive controls, and guarded negatives.

04

Prove the impact

Promote only reproducible, attacker-observable consequences with honest limitations.
